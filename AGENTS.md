# Vedel Servis: guide for AI assistants

The full guide is [CLAUDE.md](CLAUDE.md): read it first and follow it (it is written for any assistant, not only Claude). Keep answers short. Prefer doing the work in this repo over long explanations. Ask before deploy, prod data changes, or anything that touches live `servis.vedel.com.tr`.

For any non-trivial change, follow the **Test phase** section in CLAUDE.md: plan checks → code → prove with `manage.py test` and/or the manual smoke table before calling work done.
